# Engineering Interview Prep

A topic-wise learning repository for Software Developer, QA/Test Engineer, and Data Engineer interview preparation.

## Principles
- Learn concepts before memorizing answers.
- Prefer official documentation and reputable sources.
- Keep concise notes in your own words; link to sources instead of copying them.
- Include examples, exercises, common mistakes, interview questions, and revision prompts.
- Track confidence and revisit weak topics.
- Do not store secrets, credentials, personal data, or copyrighted course dumps.

## How to use
1. Start with `00-Roadmap-and-Tracking/Learning-Roadmap.md`; it is designed for someone with a job and roughly 5–6 study hours per week.
2. Pick one primary programming language.
3. Work through DSA patterns and shared CS fundamentals.
4. Choose a role track in `10-Interview-Preparation/`.
5. Build projects and practice explaining design choices.
6. Ask ChatGPT to teach one topic at a time, quiz you, and review your answers.

## Suggested topic note template
- **Goal**
- **Prerequisites**
- **Concept in my own words**
- **Why it matters**
- **Example / diagram**
- **Common mistakes**
- **Interview questions**
- **Practice tasks**
- **Source links**
- **Confidence (1–5)**
- **Next revision date**
