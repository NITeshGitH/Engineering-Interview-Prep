# System Design: LLD and HLD

LLD: requirements, entities, interfaces, SOLID, composition, design patterns, class diagrams, extensibility, and testability.

HLD: capacity estimation, APIs, data models, caching, queues, partitioning, replication, consistency, availability, observability, security, bottlenecks, and trade-offs.

For every case study, write assumptions, functional/non-functional requirements, a diagram, key decisions, failure modes, and trade-offs.
