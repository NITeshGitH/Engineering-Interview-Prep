# 1. Two Sum (LeetCode)

- **Platform**: [LeetCode #1](https://leetcode.com/problems/two-sum/)
- **Difficulty**: Easy
- **Topic**: Arrays, Hash Table

---

## Problem Statement

Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

You may assume that each input would have exactly one solution, and you may not use the same element twice. You can return the answer in any order.

### Constraints
- $2 \le \text{nums.length} \le 10^4$
- $-10^9 \le \text{nums}[i] \le 10^9$
- $-10^9 \le \text{target} \le 10^9$
- Only one valid answer exists.

---

## 1. User Submission (Java)

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int n = nums.length;
        int arr[] = new int[2];
        for(int i = 0; i<n;i++){
            for(int j = i+1; j<n;j++){
                if(nums[i] + nums[j] == target){
                    arr[0] = i;
                    arr[1] = j;
                }
            }
        }
        return arr;
    }
}
```

### Review & Evaluation
- **Correctness**: Valid brute-force logic.
- **Flaw 1 (Unnecessary execution)**: The loop does not terminate early upon finding the matching pair; it continues checking all remaining pairs until $i = n-1, j = n-1$.
- **Flaw 2 (Asymptotic Complexity)**: $O(N^2)$ time. For $N = 10^4$, $(10^4)^2 / 2 \approx 5 \times 10^7$ iterations, risking Time Limit Exceeded (TLE) under tighter constraints.
- **Time Complexity**: $O(N^2)$
- **Space Complexity**: $O(1)$ auxiliary memory.

---

## 2. Optimal Solution (Java - One-Pass Hash Map)

Instead of searching backwards through the array with a nested loop, use a hash map to trade space for time ($O(1)$ average lookup).

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[] { map.get(complement), i };
            }
            map.put(nums[i], i);
        }

        return new int[] {};
    }
}
```

### Complexity
- **Time Complexity**: $O(N)$ — Single pass; hash map insertions and lookups operate in $O(1)$ average time.
- **Space Complexity**: $O(N)$ — At most $N - 1$ entries stored in the hash map.

---

## 3. Equivalent Solution (Python)

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
        return []
```

## 4. Key Takeaways & Interview Follow-ups

1. **Trade-off**: Shifting from $O(N^2)$ time and $O(1)$ space to $O(N)$ time and $O(N)$ space is the standard baseline expectation in technical interviews.
2. **Follow-up 1**: What if the input array is already sorted?
   - Two Pointers approach ($O(N)$ time, $O(1)$ space) without needing a hash map ([LeetCode 167](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/)).
3. **Follow-up 2**: What if we need to return unique triplets that sum to 0?
   - Sort + Two Pointers with duplicate skipping ([LeetCode 15 — 3Sum](https://leetcode.com/problems/3sum/)).
