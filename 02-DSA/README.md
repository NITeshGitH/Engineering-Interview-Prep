# Data Structures and Algorithms

Learn concepts, recognize patterns, implement solutions, analyze time/space complexity, and practice explaining trade-offs aloud.

Suggested progression: Big-O → arrays/strings → hashing → two pointers/sliding window → linked lists → stacks/queues → binary search → recursion/backtracking → trees → heaps → graphs → greedy/intervals → dynamic programming → tries/bit manipulation.

For each problem record: problem link, pattern, brute-force idea, optimal idea, complexity, edge cases, and what you learned. Prefer original explanations over copied solutions.
